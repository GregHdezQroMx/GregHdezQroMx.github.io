KommHotel: 360° Hospitality Management

Fullstack Ecosystem - Hospitality & SaaS

Project Synthesis

KommHotel is a comprehensive management and booking platform developed using Compose Multiplatform (CMP), focusing on "Functional Sophistication." The solution is native and adaptive for Smartphones, Tablets as well as Desktop and Web Dashboard, following Clean Architecture best practices and Material 3 design.

The ecosystem covers everything from the guest experience to complex operational management, integrating real-time task engines, digital check-in flows, and robust financial modules.

Interaction between the guest and hotel staff, managing service requests that are instantly synchronized with the staff's task engine.

Technical Achievements

  • Adaptive white-label branding (Logo, name, and color themes).
  • Implementation of SSE (Server-Sent Events) for instant synchronization.
  • Intelligent task engine with workload-based auto-assignment.
  • Full payment integration using Stripe (Native UI + Webhooks).
  • Multi-role architecture: Guest, Staff, Manager, and System.
  • Intelligence Dashboard with performance metrics and real-time visual audit trail.

Tech Stack

Kotlin Multiplatform Compose Multiplatform Ktor Server PostgreSQL Stripe API Coroutines Koin DI

User Roles

  • Guest: Bookings and services.
  • Staff: Operational task execution.
  • Manager: Metrics and administration.
