Mix Calc

Published App - Tools & Utilities

Project Synthesis

MixCalcBiComponent is a precision tool designed for artisans and professionals working with two-component mixes (epoxy resins, silicones, polyurethanes). The application solves the critical problem of exact proportions, ensuring perfect material curing through rigorous mathematical calculations.

Developed entirely with Jetpack Compose and under Clean Architecture principles, the app offers a fluid native experience, with dark mode support and an intelligent unit conversion system that allows transitioning between weight and volume without losing calculation precision.

System Visualization

Reactive interface developed entirely with Jetpack Compose and Material 3.

Technical Achievements

  • MVVM + Clean Architecture: Clear separation of concerns for agile maintenance.
  • Dependency Injection: Implementation of Koin for efficient component management.
  • Local Persistence: Used Preferences DataStore for mix history storage.
  • Logic Validation: Unit test coverage with JUnit 4 to guarantee exact conversions.
  • UI/UX Design: Reactive interface with Material 3, Dark Mode support, and adaptive icons.
  • Offline First: Fully functional without requiring an internet connection.

Tech Stack

Kotlin 1.9+ Jetpack Compose Material 3 Koin DI DataStore JUnit 4

Key Features

  • Dual Mode: Calculate by Total Quantity or by known Portion A.
  • Pro Conversion: Real-time switching between Grams, Pounds, Ounces, Liters, and Gallons.
  • Mix History: Robust list with persistence and "Swipe-to-delete" gesture.
  • Custom Ratios: Support for any mixing ratio (1:1, 2:1, 100:42, etc).
