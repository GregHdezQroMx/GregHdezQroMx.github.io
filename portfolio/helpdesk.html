Sistema de Gestión HelpDesk

Gestión de Soporte Técnico - Enterprise Solutions

Síntesis del Proyecto

Este sistema automatiza todas las solicitudes de servicio dirigidas al departamento de sistemas mediante una estructura jerárquica de Órdenes y Tareas. Permite capturar datos críticos como la localización del usuario, la descripción del problema, el responsable asignado y el seguimiento de tiempos de respuesta y solución.

Vistas de Interfaz

Interfaz principal de "Captura de Órdenes de Trabajo" que muestra el formulario de registro, datos del usuario, responsables y bitácora de avances.

Capacidades Técnicas

  • Gestión jerárquica de órdenes de trabajo y sub-tareas.
  • Monitoreo preciso de tiempos de respuesta y resolución (SLA).
  • Reporteo de desempeño técnico y volumen de incidencias.
  • Programación de tareas de mantenimiento recurrentes o futuras.

Logros Técnicos

  • Desarrollo de un cliente de escritorio robusto para la gestión interna de sistemas.
  • Implementación de lógica de negocio para el monitoreo de SLAs en tiempo real.
  • Integración fluida con bases de datos locales para una rápida ejecución de consultas.

Tech Stack

VB 6.0 MS Access

Módulos Críticos

  • Captura y Seguimiento de Incidencias.
  • Asignación de Tareas.
  • Análisis de Desempeño.
