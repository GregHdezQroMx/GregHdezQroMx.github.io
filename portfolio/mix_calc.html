Mix Calc

App Publicada - Tools & Utilities

Síntesis del Proyecto

MixCalcBiComponent es una herramienta de precisión diseñada para artesanos y profesionales que trabajan con mezclas de dos componentes (resinas epóxicas, siliconas, poliuretanos). La aplicación resuelve el problema crítico de las proporciones exactas, garantizando que el curado de los materiales sea perfecto mediante cálculos matemáticos rigurosos.

Desarrollada íntegramente con Jetpack Compose y bajo principios de Clean Architecture, la app ofrece una experiencia nativa fluida, con soporte para modo oscuro y un sistema de conversión de unidades inteligente que permite transicionar entre peso y volumen sin perder la precisión del cálculo.

Visualización del Sistema

Interfaz reactiva desarrollada íntegramente con Jetpack Compose y Material 3.

Logros Técnicos

  • Arquitectura MVVM + Clean Architecture: Separación clara de responsabilidades para un mantenimiento ágil.
  • Inyección de Dependencias: Implementación de Koin para una gestión de componentes eficiente.
  • Persistencia Local: Uso de Preferences DataStore para el almacenamiento del historial de mezclas.
  • Validación de Lógica: Cobertura de tests unitarios con JUnit 4 para garantizar conversiones exactas.
  • Diseño UI/UX: Interfaz reactiva con Material 3, soporte para Dark Mode e iconos adaptativos.
  • Offline First: Funcionamiento total sin requerir conexión a internet.

Tech Stack

Kotlin 1.9+ Jetpack Compose Material 3 Koin DI DataStore JUnit 4

Funcionalidades Clave

  • Doble Modo: Cálculo por Cantidad Total o por Porción A conocida.
  • Conversión Pro: Cambio en tiempo real entre Gramos, Libras, Onzas, Litros y Galones.
  • Historial de Mezclas: Lista robusta con persistencia y gesto "Swipe-to-delete".
  • Ratios Custom: Soporte para cualquier relación de mezcla (1:1, 2:1, 100:42, etc).
