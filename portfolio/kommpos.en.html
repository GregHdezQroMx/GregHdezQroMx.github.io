KommPOS

Compose Multiplatform

Project Synthesis

KommPOS is a high-performance POS solution that unifies the user experience through Compose Multiplatform. By sharing 100% of the business logic and UI across platforms, we ensure agile evolution and superior stability in high-demand environments.

The system is specifically designed to support landscape format on Tablets and Desktop, maximizing operational productivity. This layout allows for a continuous sales flow where the catalog and the ticket coexist in visual harmony.

Technical Achievements

  • Multiplatform Architecture with 100% shared logic.
  • Real-time synchronization using Ktor Server and SSE (Server-Sent Events).
  • Robust local persistence with SQLDelight (Offline-first).
  • Global payment integration with Stripe API SDK.
  • Reactive and declarative UI optimized for multiple screens.
