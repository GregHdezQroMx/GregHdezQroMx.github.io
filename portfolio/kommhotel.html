KommHotel: Gestión Hotelera 360°

Ecosistema Fullstack - Hospitality & SaaS

Síntesis del Proyecto

KommHotel es una plataforma integral de gestión y reservas desarrollada con Compose Multiplatform (CMP), diseñada para ofrecer "Sofisticación Funcional". La solución es nativa y adaptativa para Smartphones, Tablets así como Desktop y Dashboard Web, siguiendo las mejores prácticas de Clean Architecture y diseño Material 3.

El ecosistema abarca desde la experiencia del huésped hasta la administración operativa compleja, integrando motores de tareas en tiempo real, flujos de check-in digital y módulos financieros robustos.

Operación en Tiempo Real: Servicio de Conserje

Interacción entre el huésped y el personal del hotel, gestionando solicitudes de servicio que se sincronizan instantáneamente con el motor de tareas del Staff.

Logros Técnicos

  • Branding adaptativo de Marca blanca (Logo, nombre y temas de colores).
  • Implementación de SSE (Server-Sent Events) para sincronización instantánea.
  • Motor de tareas inteligente con auto-asignación basada en carga de trabajo.
  • Integración completa de pagos mediante Stripe (Native UI + Webhooks).
  • Arquitectura multi-rol: Huésped, Staff, Manager y Sistema.
  • Dashboard de Inteligencia con métricas de rendimiento y auditoría visual en tiempo real.

Tech Stack

Kotlin Multiplatform Compose Multiplatform Ktor Server PostgreSQL Stripe API Coroutines Koin DI

Roles de Usuario

  • Huésped: Reservas y servicios.
  • Staff: Ejecución de tareas operativas.
  • Manager: Métricas y administración.
