KommPOS

Compose Multiplataforma

Síntesis del Proyecto

KommPOS es una solución POS de alto rendimiento que unifica la experiencia de usuario mediante Compose Multiplatform. Al compartir el 100% de la lógica de negocio y la interfaz entre plataformas, garantizamos una evolución ágil y una estabilidad superior en entornos de alta demanda.

El sistema está diseñado específicamente para soportar formato horizontal en Tabletas y Desktop, maximizando la productividad operativa. Esta disposición permite un flujo de venta continuo donde el catálogo y el ticket conviven en armonía visual.

Logros Técnicos

  • Arquitectura Multiplataforma con 100% de lógica compartida.
  • Sincronización en tiempo real mediante Ktor Server y SSE (Server-Sent Events).
  • Persistencia local robusta con SQLDelight (Offline-first).
  • Integración de pagos globales con Stripe API SDK.
  • Interfaz reactiva y declarativa optimizada para múltiples pantallas.
